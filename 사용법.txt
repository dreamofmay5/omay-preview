오월의꿈 홈페이지 시안 (실제 동작 버전)

■ 내 PC에서 보기
  1) Node.js 가 설치된 PC 에서 "미리보기_실행.bat" 을 더블클릭합니다.
  2) 브라우저에서 http://localhost:8080/ 가 열립니다. (이 창을 닫으면 종료)
  ※ index.html 을 그냥 더블클릭하면 화면이 나오지 않습니다. 반드시 위 방법이나 웹 호스팅을 이용하세요.

■ 다른 사람에게 링크로 보여주기 (웹 호스팅에 올리기)
  이 폴더 전체를 정적 웹 호스팅에 올리면 누구나 링크로 볼 수 있습니다.
  예) Netlify Drop (https://app.netlify.com/drop) 에 폴더를 끌어다 놓기
      Cloudflare Pages / GitHub Pages / Vercel 도 가능
  - 모든 페이지에 검색엔진 비노출(noindex) 설정과 robots.txt 차단이 들어 있어 검색에 잡히지 않습니다.
  - 링크를 아는 사람은 누구나 볼 수 있으므로 시안 공개 범위에 유의하세요.
  - 사이트를 내릴 때는 호스팅에서 해당 사이트를 삭제하면 됩니다.

■ 알려 드립니다
  - "GEO 엔티티 체크", "AI 크롤러 접근 점검"의 URL 입력 기능은 별도 진단 서버가 필요해 이 시안에서는 동작하지 않습니다. (안내 메시지가 표시됩니다.)
  - 칼럼 예시 글과 포트폴리오의 [입력] 표시는 확정 전 내용입니다.
  - 문의 폼은 화면만 있고 실제 전송은 연결되어 있지 않습니다.
